## Co działa

- **`PlayerCommand`** (5 pól −1…1): `Forward`, `Strafe`, `Turn`, `Kick`, `Loft`. W G2 **Kick/Loft nie wywołują impulsu** ani kopnięcia.
- **Wejście areny:** `ArenaController.SubmitCommand(playerId, command, commandId)` — ostatnia komenda przed krokiem fizyki zastępuje poprzednią; ruch/obrót utrzymują się do następnej komendy.
- **`PlayerMotor`:** Rigidbody dynamiczny, grawitacja, blokada obrotu X/Z, ruch XZ względem orientacji (+Z przód, +X prawo), `ClampMagnitude` wektora (Strafe, Forward), dojście do prędkości z limitem przyspieszenia, zachowana składowa Y prędkości.
- **`MovementConfig`** (ScriptableObject): 4 m/s, 20 m/s², 180°/s.
- **`KeyboardCommandSource`:** Unity Input System (`Keyboard.current`); W/S, A/D, Q/E; puszczenie klawiszy → komenda zerowa ruchu; utrata fokusu zeruje ruch. Spacja, strzałki, R **ignorowane** (G3/G4).
- **`KeyboardCommandMapping`:** czysta funkcja mapowania (testy EditMode).
- **`ArenaDebugHUD`:** Forward, Strafe, Turn; Kick/Loft wyświetlane jako 0.
- **Zawodnik:** `Player_0` pod `Arena/Players`, ~0,8×1×0,8 m, `PlayerId=0`, `TeamId=0`, start (0, 0,5, −3) względem areny.
- **Kolejność kroku:** wyłącznie `ArenaController.FixedUpdate` → `StepPlayerMotors` → `PlayerMotor.ApplyCommand`; brak ruchu w `Update` innych komponentów.
- **Narzędzia idempotentne:** menu **FootballRL → G2 → Ensure Player And Arena Setup**; batchmode `FootballRL.Editor.G2Verification.RunBatch`.

**Poza zakresem G2 (nie zaimplementowano):** kopnięcie, GoalDetector, reset epizodu, snapshot, SpawnSampler, nagrody, bot, ML-Agents.

**Git:** brak commita.

## Jak uruchomić

1. Unity **6000.6.2f1** → projekt `unity/FootballRL`.
2. Jeśli brak zawodnika po rebuildzie G1: **FootballRL → G2 → Ensure Player And Arena Setup**.
3. Otwórz scenę **`ManualPlayground`**, **Play**.
4. Sterowanie: **W/S** przód/tył, **A/D** strafe, **Q/E** obrót. HUD w lewym górnym rogu pokazuje komendy.
5. Pchanie piłki: podejdź colliderem (bez kopnięcia).

Weryfikacja batch (projekt wolny, bez drugiej instancji Unity):

```text
Unity.exe -batchmode -nographics -quit -projectPath ... -executeMethod FootballRL.Editor.G2Verification.RunBatch -logFile unity/g2-verify.log
```
