## Co działa

- **`KickConfig`** (ScriptableObject): próg 0,2, maxImpulse 8 N·s, cooldown 0,25 s, zasięg 1,1 m, stożek ±45°, max wysokość środka piłki 0,5 m nad podłożem (Y=0).
- **`PlayerKicker`** (logika statyczna): warunki, impuls `AddForce(Impulse)`, kierunek `forward*cos(α)+up*sin(α)`, przesłonięcie (raycast, wykluczenie colliderów gracza i boiska).
- **`PlayerKickAnchor`** + **`KickPoint`** na prefabie gracza (domyślny offset lokalny 0,15 / 0,45 m).
- **`ArenaController`:** jeden krok — cooldown → **`StepPlayerMotors`** → **`StepPlayerKicks`**; `commandId` zużywane raz na próbę kopnięcia; cooldown tylko po sukcesie; zdarzenie **`KickSucceeded`** (lokalne C#).
- **Klawiatura (Input System):** W/S, A/D, Q/E bez zmian; ↑↓ kąt 0–55° (krok 5°); ←→ siła Kick 0–1 (krok 0,05, start 1); **Spacja** — zbocze, nowy `commandId`, Kick/Loft z wyboru; **R** bez resetu; utrata fokusu zeruje ruch i anuluje oczekujące kopnięcie.
- **`ArenaDebugHUD`:** kąt, siła, cooldown, ostatnia próba (sukces / powód odmowy); Loft faktyczny (nie na sztywno 0).
- **`KickRangeVisualizer`:** LineRenderer — łuk 1,1 m i linie stożka ±45°.
- Menu **FootballRL → G3 → Ensure Kick Setup** (idempotentne, po G2).

**Poza zakresem G3:** gol, reset epizodu (R), snapshot, nagrody, bot, ML-Agents.

**Git:** brak commita.

## Jak uruchomić

1. Unity **6000.6.2f1** → `unity/FootballRL`.
2. **FootballRL → G3 → Ensure Kick Setup** (jeśli brak punktu kopnięcia po G1/G2).

```text

```
